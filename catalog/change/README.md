# Occurrence change intensity

Change in water occurrence between 1984-1999 and 2000-2024, from homologous months. 100 is no change. From the [GSW v1.5 Data Users Guide](https://storage.googleapis.com/water-world/downloads_ancillary/DataUsersGuidev2024_v.5.pdf): "Change in water occurrence intensity between two epochs (16 March 1984 to 31 December 1999, and 1 January 2000 to 31 December 2024) was also produced. This is derived from homologous pairs of months (that is, the same months contain valid observations in both epochs). [...] Areas where there are no pairs of homologue months could not be mapped." The collection holds the 504 upstream 10° × 10° tiles as items, copied byte for byte (0.00025° grid, EPSG:4326, uint8, nodata 255), and one global overview COG at 0.004° for display. Read [AGENTS.md](AGENTS.md) for access patterns.

## Quick Start

```python
import rasterio
from rasterio.windows import from_bounds

# One 10° tile; rasterio fetches only the blocks inside the window.
url = "https://data.source.coop/portolan-mirrors/global-surface-water/change/100E_20N/100E_20N.tif"
with rasterio.open(url) as src:
    win = from_bounds(103.6, 12.4, 104.6, 13.2, src.transform)  # Tonle Sap
    data = src.read(1, window=win)  # 255 is no data; the file sets no NoData tag
    print(data.shape, src.crs)
```

## Known Issues

The Data Users Guide lists two bands for occurrence change intensity (`change_abs` and `change_norm`); the downloadable tiles hold one band, which matches the `change_norm` value table. The guide states that seasonality covers only 2022 to 2024 and that 2022 onward uses Landsat Collection 2, which "introduces a residual co-registration offset" of up to about one 30 m pixel in some path/rows. Monthly history, yearly history, and monthly recurrence are not in this mirror.
